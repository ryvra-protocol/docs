# Security Policy

## Reporting a vulnerability
Do not open public issues for security-sensitive findings.

Please report vulnerabilities privately to the Ryvra maintainers through the repository's security advisory workflow or designated security contact channel.

## Scope
Security reports may include:
- Documentation errors that could cause unsafe protocol operation.
- Incorrect risk controls, governance steps, or release procedures.
- Misleading tokenomics/compliance statements.

## Response expectations
Maintainers will acknowledge reports, triage severity, and provide remediation timelines based on impact.
