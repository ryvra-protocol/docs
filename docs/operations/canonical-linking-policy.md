# Canonical Linking Policy

## Source of truth
This repository is the canonical source for RFCs, tokenomics, governance, and related policy/process documentation.

## Linking rules
- Other Ryvra repositories MUST link to canonical docs in this repository for normative references.
- Mirrors MAY exist for convenience but MUST clearly declare non-canonical status.
- Canonical references SHOULD use stable paths and RFC identifiers.
- Cross-repository PRs SHOULD use
  [`/docs/operations/repo-alignment-checklist.md`](./repo-alignment-checklist.md)
  to map legacy in-repo doc paths to canonical docs paths.
