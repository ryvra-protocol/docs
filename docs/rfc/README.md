# RFC Index

Ryvra RFCs define protocol-level and interface-level requirements for implementation repositories.

## RFC process overview
1. Author drafts using `/docs/reference/templates/rfc-template.md`.
2. RFC enters **Draft** and receives cross-repo review.
3. RFC moves to **Review** when scope and impact are stable.
4. RFC is marked **Accepted** after governance approval.
5. RFC may become **Superseded** by a newer accepted RFC.

## Status definitions
- **Draft**: Proposal in progress; details may change.
- **Review**: Under active formal review by maintainers/stakeholders.
- **Accepted**: Approved as canonical guidance.
- **Superseded**: Replaced by another RFC.

## Template usage
Use `/docs/reference/templates/rfc-template.md` and complete all required sections, including compatibility, risks, and related RFC references.
