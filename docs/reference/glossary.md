# Glossary

- **RFC**: Request for Comments protocol/design document.
- **PoT**: Proof of Transaction pre-TGE points program.
- **TGE**: Token Generation Event.
- **Normative**: Required behavior or policy guidance.
- **TBD by governance/policy**: Deferred parameter awaiting formal approval.
- **UserOperation**: ERC-4337 transaction intent envelope submitted through bundlers.
- **ALLOW / DENY / REVIEW**: Policy verdict classes where only ALLOW may execute.
- **Canonical asset identity**: Immutable `asset_id` + network binding issued by asset-registry.
