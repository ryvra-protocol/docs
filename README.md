## How to propose changes (quick flow)
1. Open an issue using a docs or RFC template.
2. Draft changes using repository templates and style guide.
3. Run markdown and link quality checks with pnpm.
4. Submit PR for code owner and domain review.
5. Merge and update changelog/decision log as required.
